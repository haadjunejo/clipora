# Code of Conduct

Clipora follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, give constructive feedback, and keep discussions about
the project. Harassment, insults and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer through GitHub. Maintainers may remove comments, commits
or contributors that break these rules.
